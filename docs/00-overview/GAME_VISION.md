# GAME_VISION

## 1. 产品定义

《史纪》是一款以真实中国历史为骨架的**单人剧情战争游戏**。

玩家扮演一名现代游戏宅男，穿越到北宋末年，从基层军官起步，在真实历史事件中不断升迁。玩家知道部分历史结局，因此会主动尝试干预战争、救人、改变决策；但随着干预增多，原本掌握的“历史攻略”会逐渐失效。

第一部暂定《史纪：汴京》。

## 2. 第一部历史范围

- 时间：**1115—1127**
- 核心城市：东京汴京（今河南开封）
- 叙事方式：章节制 + 时间跳跃
- 世界结构：汴京作为长期叙事枢纽，战役采用独立或半开放地图
- 终局历史锚点：靖康与北宋灭亡

选择 1115—1127 的目的不是逐年模拟，而是覆盖北宋末期最适合战争成长线的关键阶段，并允许主角在约十二年的跨度内完成从基层军官到高级将领的戏剧性成长。

## 3. 玩家身份

玩家不是上帝视角的国家统治者，而是**真实存在于历史中的一名军人**。

玩家直接控制：

- 自身移动与战斗
- 技能、装备、战马
- 与人物对话及关键选择
- 对所属军团下达有限军令
- 对军资、装备和物资做有限倾斜

玩家不能直接控制：

- 每一个农民和士兵
- 国家全部经济
- 整个王朝行政系统
- 所有友军的即时行为

## 4. 核心体验

游戏应同时满足五种体验：

1. **英雄感**：玩家亲自进入战场，并能凭操作改变局部战斗。
2. **统军感**：玩家控制的是“意图和命令”，而不是逐个士兵。
3. **历史感**：真实人物、城市、制度和重大事件构成可信世界。
4. **成长感**：从基层军官逐步获得兵权、资源、人脉和政治影响力。
5. **宿命感**：玩家可以改变很多人的命运，但无法轻易逆转时代大势。

## 5. 设计支柱

### 玩家首先是一个人

视角、权限和资源都受身份限制。官职越高，可影响的军队和资源越多。

### AI 军队不是鼠标单位

士兵和军团拥有自主行为。玩家通过“攻、守、援、撤”等军令表达战略意图。

### 手机不是缩水版 PC RTS

手机端仍以英雄操作为中心；军团与经济通过自动化和少量高价值决策控制，不要求高频框选与微操。

### 中国历史必须进入玩法

中国元素不能只停留在建筑皮肤。诏令、军功、官职、粮秣、军令、朝廷关系和历史人物都应形成实际玩法。

### 历史主线稳定，个人命运可变

重大历史锚点保持不变；局部战役、支线人物和玩家个人结局允许明显变化。

## 6. 非目标

第一阶段明确不做：

- 开放世界
- 国家级 4X 模拟
- 传统全功能 RTS
- MMO
- PvP / 排位
- 城建手游式长期运营
- 历史沙盒“随意改朝换代”
- 靠现代科技碾压古代的工业穿越爽文

## 7. 成功标准

MVP 成功不是“内容很多”，而是玩家能够明确感受到：

> 我亲自控制一名将领作战，我的军队会自己打仗，但我的军令、资源投入和个人行动确实改变了战局。

如果这个体验不成立，其余剧情、建筑、历史考据和长期系统都不继续扩张。
