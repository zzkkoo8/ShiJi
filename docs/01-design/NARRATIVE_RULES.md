# NARRATIVE_RULES

## 1. 叙事核心

《史纪》的主题不是“穿越者靠现代知识改写一切”，而是：

> **知道历史结局的人，能否在无法逆转的大势中改变具体的人与事。**

第一部必须让玩家持续感受到：自己的选择真实有效，但历史并不是一个只靠知道答案就能轻易重写的剧本。

## 2. 三层历史规则

### 2.1 历史锚点：不可改变

历史锚点决定第一部主线最终仍与真实历史一致，例如：

- 女真崛起并建立金朝
- 辽朝走向灭亡
- 宋金关系由合作转向战争
- 金军南下
- 靖康危机发生
- 北宋灭亡

玩家不能通过一个选项直接删除这些事件。

### 2.2 历史过程：允许扰动

玩家可改变重大历史之间的局部过程，例如：

- 某场战斗胜负和伤亡
- 某城坚持时间
- 某次情报是否及时送达
- 某支军队是否保存下来
- 某次错误命令是否被局部纠正
- 某批物资是否送达前线

过程变化应反馈到后续任务，而不是选择结束后立即被完全抹平。

### 2.3 人物命运：高度可变

人物层是玩家选择最主要的反馈区域：

- 战友生死
- 部将忠诚与去留
- 村镇和百姓命运
- 玩家仕途
- 玩家与历史人物的关系
- 支线人物最终归宿

历史书可能没有记下这些人，但游戏必须记下。

## 3. 历史为什么“不可逆”

不要使用神秘的“世界自动修正历史”作为主要解释。

历史锚点应主要由现实因果推动：

- 制度与政治结构
- 多方利益
- 军事力量差距
- 财政与后勤
- 信息不对称
- 人物性格与权力关系
- 玩家职位和影响范围有限

玩家可以赢一场仗，却无法凭一人同时解决整个国家的所有问题。

## 4. 穿越者的知识边界

主角是现代**游戏宅男和历史爱好者**，不是历史学家、工程院院士或全能特种兵。

他知道：

- 时代大概走向
- 部分著名人物和事件
- 常识性的现代管理/军事概念
- 大量游戏中的策略思维

他不知道：

- 每一天发生的具体事件
- 每支部队的真实部署
- 所有历史人物的细节
- 古代技术的完整制造工艺
- 如何凭空建立现代工业体系

允许主角记错、记混、只知道结论不知道原因。

## 5. 蝴蝶效应

玩家改变越多，主角原本掌握的历史信息越不可靠。

设计原则：

```text
原历史：A → B → C → D
玩家改变 B：A → B' → C? → D
```

历史锚点 D 仍可能发生，但中间过程不再与玩家记忆完全一致。

这既限制“背攻略穿越”，也为后续剧情提供未知感。

## 6. 真实历史人物

历史人物分三类处理：

### 核心历史人物

其关键身份、重大行为和史书记载结局原则上不改。

### 次级历史人物

在不破坏已知史实的前提下，可以扩展未被史料详细记录的经历。

### 游戏原创人物

承担最主要的分支、友情、爱情、牺牲和长期关系变化。

禁止为了制造爽点，把真实人物简单改造成现代网络标签式的“忠臣/奸臣/废物/神将”。

## 7. 史实与虚构标识

历史内容在设计阶段必须标记：

- `史实`：有可靠来源支持
- `合理复原`：史料缺失，根据同时代证据推断
- `游戏虚构`：为玩法或人物线创作

玩家最终可通过图鉴/史记系统了解哪些内容属于真实历史，哪些属于游戏演绎。

## 8. 任务选择

有意义的选择必须至少满足一项：

- 牺牲一种利益换取另一种利益
- 影响人物命运
- 改变之后任务条件
- 改变玩家职位、声望或关系
- 改变局部战役结果

避免只有不同对白、实际结果完全相同的伪选择。

## 9. 结局原则

第一部历史主线最终仍进入靖康与北宋灭亡。

结局重点不评价“玩家有没有改朝换代”，而总结：

- 救下了谁
- 失去了谁
- 哪些地方因玩家而改变
- 玩家最终成为怎样的人
- 玩家是否仍相信“知道历史就能改变历史”

核心表达：

> **史可扰，人可救，势不可逆。**
