# RESEARCH_SOURCES

本文件记录《史纪：汴京》的历史、美术和制度资料入口。目标不是堆链接，而是建立**可追溯证据链**。

## 1. 证据等级

历史与美术设计按以下顺序取证：

1. 考古发掘报告、国家/省级文物部门资料
2. 博物馆藏品与官方图录
3. 同时代原始文献、图像和实物
4. 现代学术专著与论文
5. 高质量学术复原
6. 游戏艺术推断

百科、短视频、论坛只能用于发现线索，不能作为关键史实的最终依据。

## 2. 第一批核心资料

### 《清明上河图》

用途：东京城市生活、街道、商业、交通、人物活动与建筑视觉参考。

- 故宫博物院藏品页：
  https://www.dpm.org.cn/collection/paint/228226.html

注意：画面可作为北宋城市视觉证据，但不能把画中所有建筑直接解释为某一具体实名建筑。

### 《东京梦华录》

用途：北宋东京城市空间、节庆、饮食、商业和社会生活。

开发要求：使用可靠整理本，并在具体剧情引用时记录卷次/条目，而不是只引用现代转述。

### 《营造法式》

用途：北宋官式建筑制度、构件、尺度、施工和装饰参考。

- 国家图书馆出版社相关资料：
  https://www.nlcpress.com/ProductView.aspx?Id=12860

注意：不能把《营造法式》理解为“所有宋代民居都严格按同一模板建造”。

## 3. 东京城考古

### 景龙门遗址

河南省/开封市考古成果显示，景龙门为北宋东京里城重要城门，已确认一门三道等结构，并提供较明确的尺度、筑造方式和位置关系。

- 河南省文物考古研究院：
  https://www.hnswwkgyjy.cn/NewsView.php?News_ID=2399
- 开封市文化广电和旅游局：
  https://wgl.kaifeng.gov.cn/kfswhgdhlyj/swgljbhwwc/pc/content/content_1878699220689305600.html

用途：城门、城墙、御道附近场景复原的重要标尺。

### 顺天门遗址

- 河南省文物考古研究院：
  https://www.hnswwkgyjy.cn/NewsView.php?News_ID=604

用途：东京外城城门、瓮城、道路、墙体尺度与筑造方式。

## 4. 人物与时代实物

### 宋徽宗赵佶

国家博物馆“崇宁四年赵佶投龙玉简”资料记录赵佶 1100 年即位及靖康二年被俘北行等基础信息，同时提供北宋宫廷、道教和玉器文化实物线索。

- 中国国家博物馆：
  https://www.chnmuseum.cn/zp/zpml/201812/t20181218_24587.shtml

### 靖康时期货币

- 中国国家博物馆货币藏品目录含“靖康通宝”等北宋末年实物：
  https://www.chnmuseum.cn/zp/zpml/hb/

用途：货币、UI 图标、经济道具及时代物质文化参考。

## 5. 线下调研优先级

第一批河南实地调研建议：

1. 开封市博物馆
2. 北宋东京城相关考古展示/成果
3. 铁塔（祐国寺塔）
4. 繁塔
5. 州桥及汴河遗址相关展示
6. 河南博物院宋代相关藏品

现场重点不是“拍旅游照片”，而是记录：

- 建筑尺度
- 材质与纹理
- 瓦当、砖石、栏杆、门窗等细部
- 器物尺寸
- 展签和参考文献
- 城市地形与水系关系
