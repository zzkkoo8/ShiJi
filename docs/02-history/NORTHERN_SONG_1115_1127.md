# 北宋 1115—1127：第一部历史框架

> 本文是立项级历史框架，不是最终编剧史料。进入具体任务设计前，事件日期、人物在场情况、军制、地名和建筑必须逐条核验。

## 1. 为什么选择这段历史

第一部选择北宋末期，核心原因：

- 东京汴京是成熟的大都会，可形成高辨识度城市枢纽。
- 开封现有大量北宋都城考古成果，便于线下调研和建筑复原。
- 《清明上河图》《东京梦华录》《营造法式》等资料能同时支撑城市、社会与建筑设计。
- 1115—1127 的政治和战争变化剧烈，适合“基层军官 → 高级将领”的成长线。
- 玩家已知“靖康”结局，天然形成穿越者试图干预历史的戏剧压力。

## 2. 时间范围

**1115—1127**。

游戏不逐年连续模拟，而采用章节和时间跳跃。历史主线建议按以下阶段组织。

### 序章：1115—1119

定位：主角穿越、进入军队、认识东京与北宋社会。

作用：

- 建立现代人与古代制度的冲突
- 学习基础战斗与军令
- 从最低军职开始建立人际关系
- 让玩家先看到一个仍然繁华、自信的东京

1115 年金朝建立，是第一部外部格局变化的重要起点。

### 第一阶段：1120—1121

核心背景：北宋内部动荡及方腊起义时期。

游戏价值：

- 主角第一次参与真正的大规模军事行动
- 展示北宋军队、地方社会与朝廷命令之间的关系
- 给玩家第一次“知道结局但不知道细节”的体验
- 建立军功与升迁

是否让主角直接参与具体历史战场，需要在后续史料核验后确定；不能为了覆盖著名事件强行让主角出现在所有关键现场。

### 第二阶段：1122—1124

核心背景：宋辽金格局快速变化，北方战争扩大。

游戏价值：

- 从国内军事任务转向边境与国家战争
- 引入辽、金不同军队和战术风格
- 玩家开始意识到自己熟悉的历史大势正在逼近
- 玩家职位上升，可首次真正指挥完整军团

### 第三阶段：1125—1126

核心背景：宋金关系破裂，金军南下，东京面临直接军事压力。

游戏价值：

- 战争从远方进入玩家熟悉的城市和人物生活
- “守城、撤退、救援、军粮、诏令冲突”成为主要任务类型
- 玩家开始有能力改变局部战役，却越来越无法控制全国局势

宋徽宗于 1100 年即位；国家博物馆资料记载其在靖康二年（1127）被金兵俘虏北行，可作为这一时代线的重要人物背景依据。

### 终章：1126—1127

核心背景：靖康危机与北宋灭亡。

玩家可能：

- 救下本应死去的原创或次级人物
- 保存部分军队与物资
- 改变局部守城结果
- 让更多百姓撤离
- 因奉诏或违诏得到不同个人结局

但历史锚点不变：北宋最终灭亡。

## 3. 东京汴京：第一部核心枢纽

北宋东京城位于今河南开封。河南省文物考古研究院公布的考古成果显示，东京城由**外城、里城（内城）、大内（皇城）三重城垣**组成，总面积约 **53 平方公里**。

游戏不按 1:1 比例复原完整 53 平方公里城市。第一阶段采用“代表性区域 + 可验证建筑尺度”的方式复原。

优先区域：

- 城门与御道
- 军营及相关军事设施
- 市井与商业街区
- 汴河、桥梁和码头
- 官署外围
- 普通居民区

皇城内部只有在剧情真正需要时才制作。

## 4. 建筑复原原则

优先级：

```text
考古证据
> 同时代实物建筑
> 同时代图像
> 同时代文献
> 现代学术复原
> 艺术推断
```

例如景龙门的考古成果已经提供一门三道、尺度、墙体与基础构造等实证信息，并可与《营造法式》互证；这种资料应优先于通用“中国古风”素材。

## 5. 世界不是“宋朝主题公园”

历史场景应同时表现：

- 东京的商业繁荣
- 普通人的生计
- 军队与官僚系统
- 物流与粮食
- 社会阶层
- 城内外差异
- 战争逐步逼近对日常生活的破坏

玩家应先喜欢和熟悉这座城，终局的失去才有意义。

## 6. 主角成长节奏

十二年的时间跨度不意味着十二年连续游玩。

建议使用时间跳跃，让主角经历：

```text
基层军官
→ 带领小队
→ 独立带兵
→ 军团级指挥权限
→ 终局中的重要将领
```

具体宋代军职名称必须经过军制史料核验后再正式写入游戏，当前文档不提前锁定错误官名。

## 7. 历史内容开发流程

每一个正式历史任务至少需要：

1. 事件时间与地点来源
2. 相关人物来源
3. 当时军政关系来源
4. 地图/建筑依据
5. `史实 / 合理复原 / 游戏虚构` 标识
6. 与历史锚点冲突检查

史料不足时允许虚构原创人物和局部事件，但不能伪装成史实。
