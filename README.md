# 史纪 / ShiJi

> 工作名：**《史纪：汴京》**

《史纪》是一款以真实中国历史为骨架的单人剧情战争游戏。玩家扮演一名现代游戏宅男，意外穿越到北宋末年，从军队基层武官起步，在真实历史事件中升迁、作战、结交人物并尝试改变历史。

玩家主要直接操作一名将领；军队与经济系统大部分由 AI 自主运行，玩家通过军令、资源调配、装备赏赐和亲自参战间接改变战局。局部事件和人物命运可以改变，但第一部的历史主线最终仍走向靖康与北宋灭亡。

## 第一部

- 暂定名：**《史纪：汴京》**
- 历史范围：**1115—1127**，采用章节化时间跳跃，不连续模拟十二年
- 核心地点：北宋东京汴京（今河南开封）
- 结构：**汴京枢纽 + 章节化战役地图**，不做开放世界
- 平台目标：Windows PC + Android，iOS 后置
- 当前阶段：立项 / 核心玩法验证

## 当前原则

1. 先验证“英雄直接操作 + AI 军团 + 军令 + 皇诏任务 + 历史选择”是否好玩。
2. 不把 PC 传统 RTS 的微操直接搬到手机。
3. 不做开放世界，不先做多人联机，不先上 DOTS/ECS。
4. 史实、建筑、服饰、武器等内容必须有可追溯依据；不允许仅凭 AI 印象生成。
5. 技术优先使用 Unity 官方能力和普通 C#，避免过早引入大型框架。
